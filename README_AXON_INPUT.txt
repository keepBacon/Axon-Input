Axon Input 1.5

用途
- 显示外接键盘、鼠标和手柄输入状态。
- 提供 CPS、最近按键、鼠标轨迹、全键盘输入显示、手柄摇杆/扳机显示。
- 提供鼠标和右摇杆灵敏度倍率。
- 支持自定义字体和自定义 HTML 显示。

当前主要功能
1. 键盘按显
- W / A / S / D / Space。
- 缩放、透明度、按键间距、按键形状、按下颜色、按下动效。
- Space 可显示 CPS。

2. 鼠标按显
- 左右键连体显示，中间使用分隔线。
- 支持缩放、透明度、按键形状、按下颜色和按下动效。
- 支持鼠标左右键 CPS。

3. 自定义按键
- 录入外接键盘按键。
- 支持列数、缩放、透明度、间距、按键形状、按下颜色和按下动效。

4. 最近按键
- 最多显示 6 个最近输入。
- 支持 CPS、透明度、按键形状、按下颜色和扩散反馈。

5. 输入时显示全键盘
- 输入法打开时自动显示。
- 输入时对应按键高亮。
- 输入法关闭后自动隐藏。
- 只显示，不接收触摸。

6. 手柄显示
- 左右摇杆、ABXY、L1/L2、R1/R2。
- ABXY 支持缩放、透明度、间距、按键形状、按下颜色和 CPS。
- 肩键支持透明度、按键形状、按下颜色、L1/R1 CPS 和 L2/R2 压力。

7. 手柄兼容调试
- 自动：默认。
- 宽松合并：按键缺失时尝试。
- Android 优先：串键或错键时尝试。
- 底层优先：系统映射异常时尝试。
- 独立修正：交换 X/Y、A/B、左右摇杆、L2/R2。

8. 灵敏度倍率
- 鼠标与右摇杆范围 1–500%。
- 100% 保持原始倍率。
- 1–200% 按 1% 调节，200–500% 按 5% 调节。
- 支持 Shizuku 免 Root和 Root。
- 手柄优先选择轴和按键最完整的输入节点，减少复合手柄接管错误。
- 右摇杆高倍率自动增加少量中心防漂移，并校准轻微零点偏差。
- 状态显示“手柄已接管 · 游戏输入已替换”后，游戏才会收到处理后的虚拟手柄输入。
- 注意：可能无法绕过部分应用内部灵敏度上限。

9. 自定义字体
- 支持 TTF / OTF。
- 字体复制到应用内部目录并缓存。

10. 自定义 HTML
- HTML API v10。
- 支持 HTML、CSS、JavaScript、SVG、Canvas、Web Animations。
- 支持 localStorage / sessionStorage。
- 支持读取按键外观、间距、透明度、手柄兼容状态等只读数据。
- HTML 最大 4 MB。
- 网络访问关闭。
- 详细说明：HTML_API_V10_CN.txt。

配置
- 普通返回、切后台、重新打开 Activity 不清除当前设置。
- 从最近任务中真正移除应用任务后，当前运行配置按既定逻辑清理。
- 配置 1 可保存、载入、导出和导入。
- 配置导入保留访问验证状态。

签名
- 启动时只执行一次 APK 证书 SHA-256 校验。
- 签名密钥默认保存在 ~/.axon-input/axon-input.keystore。
- 后续版本需要保留同一密钥，才能覆盖安装。


1.4 手柄倍率修复
- 手柄倍率改为直接放大右摇杆输出，200% 时约半推即可达到满量程。
- 虚拟手柄继承物理手柄的总线、VID/PID 和版本，减少游戏识别为不同控制器导致的映射差异。
- 保留高倍率中心防漂移。
- 摇杆 HID 输出最大仍为 100%，因此满摇杆无法超过游戏自身允许的最大转向速度。
1.4 手柄倍率二次修复
- 启动代理前清理上一次残留的 Shizuku/Root 代理，避免多个虚拟手柄同时转发。
- 同时接管一个手柄暴露的多个 evdev 节点，不再只处理评分最高的单一节点。
- RX/RY、Z/RZ 中静止在中点附近的轴都会应用右摇杆倍率，减少不同手柄轴布局导致倍率打错轴。
- 物理节点由 EVIOCGRAB 接管后再通过 uinput/UHID 转发，避免游戏继续收到同节点的原始输入。


1.4 右摇杆视角倍率三次修复
- 100% 保持原始手柄右摇杆，不再对高倍率做摇杆提前饱和。
- 超过 100% 的部分转换成独立的相对视角输入，持续输出，不受摇杆 [-1, 1] 最大值限制。
- 视角输入优先使用 uinput 相对鼠标，失败时回退 UHID。
- 额外视角输入使用 8 ms 节拍、中心死区和轻微曲线，减少高倍率漂移并保留轻推精度。
- 低于 100% 时仍使用原有右摇杆降倍率。
