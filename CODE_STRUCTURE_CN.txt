Axon Input 版本：1.0

Axon Input 代码结构说明

目标
- 配置、输入、绘制、权限分别处理，减少一个文件承担过多职责。
- 高频输入路径不做磁盘写入，不频繁创建临时对象。
- 关键类使用中文注释说明职责、数据来源和性能选择。

1. MainActivity.java
负责设置界面、密码弹窗、文件选择器和权限入口。
新的根任务进入时调用 OverlayState.beginAppSession()，普通配置恢复默认。
已经通过密码验证后，每次进入都会自动执行 ensureAccessibility()。

2. OverlayState.java
所有设置的统一读写接口。界面和无障碍服务都只通过这里读取配置。
普通运行设置不会直接使用磁盘 SharedPreferences。

3. SessionPreferences.java
内存版 SharedPreferences。
开关、位置、大小、颜色、灵敏度等仅当前会话有效。
应用重新进入新任务时 reset()；进程被系统结束后内存也自然消失。

4. ConfigManager.java
“配置1”的显式保存、加载、导出、导入。
只有用户主动操作时才写文件。密码授权和临时录入状态不会进入配置文件。

5. AxonInputAccessibilityService.java
全局输入和悬浮窗的中心调度器。
- 键盘 KeyEvent
- 手柄 Android 语义按键
- 鼠标/手柄原始遥测
- 各悬浮窗创建、更新、移除
onKeyEvent() 始终返回 false，不消费游戏原始按键。

6. GamepadButtons.java
手柄数字键的语义映射集中在一个文件。
A/B/X/Y 使用 Android KeyEvent 语义；摇杆和扳机继续使用原始输入。
这样 X/Y 修复不会散落在多个 View 或 native 文件中。

7. MouseInputMonitor.java / GamepadInputMonitor.java
只负责读取底层输入并上报，不负责绘制。
GamepadInputMonitor 不独占设备，普通显示模式不会阻止游戏收到手柄输入。

8. SensitivityProxyController.java + native/sensitivityproxy.cpp
只处理灵敏度超频。
免 Root 通过 Shizuku，Root 通过 su；持续输入变换在 native 进程完成。

9. KeyOverlayView / NativeKeyCanvasView
键盘、鼠标、自定义键位的窗口容器和原生绘制。
每个键有独立动画状态。

10. MouseTrajectoryView.java
只保存轨迹圆点的目标、速度和位置。
动画稳定后停止请求下一帧。

11. GamepadOverlayView.java
左/右摇杆、ABXY、左/右肩键的原生绘制和动效。
不读取设备文件。

12. KeyPromptOverlayView.java
最近按键提示的适配实现。
维护最近按键、CPS、释放停留和位置让位；HTML 开启时把同一状态交给 HTML。

13. GlobalHtmlWebView.java
HTML 自定义显示层，API v9。
- 完整 state/palette/runtime/settings
- 细粒度 key/mouse/pointer/gamepad 事件
- 高频 pointer/gamepad 按显示帧合并并只发送局部状态
- HTML 关闭时不创建 WebView

14. HtmlGuideActivity.java
应用内 HTML 文档，示例应与 GlobalHtmlWebView API 同步。

推荐阅读顺序
MainActivity
-> OverlayState / SessionPreferences
-> AxonInputAccessibilityService
-> 各 OverlayView
-> GlobalHtmlWebView
-> native
