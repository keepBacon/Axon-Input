Axon Input 2.0 代码结构

原则
- 配置、输入、绘制、权限分开处理。
- 高频输入路径不写磁盘。
- 高频绘制避免重复创建对象。
- 公共状态由 OverlayState 统一读写。
- HTML API 只提供输入和只读配置，不开放系统权限接口。

主要文件

MainActivity.java
- 设置界面。
- 访问验证。
- 文件导入导出。
- Shizuku / Root 入口。
- KOOK、by Bacon、版本提示等界面操作。

OverlayState.java
- 所有运行设置的统一读写入口。
- 管理位置、大小、透明度、按键样式、颜色、间距、手柄兼容等状态。
- 管理自定义 HTML 文件。

ConfigManager.java
- 配置 1 保存、载入、导入和导出。
- 使用原子文件替换，降低写入中断导致的损坏风险。
- 导入配置时保留访问验证状态。

AxonInputAccessibilityService.java
- 全局输入调度。
- 创建和更新悬浮组件。
- 汇总键盘、鼠标、手柄和 CPS 状态。

GamepadButtons.java
- 手柄数字按键语义映射。
- 处理兼容模式和独立按键交换。

MouseInputMonitor.java
GamepadInputMonitor.java
TouchInputMonitor.java
native/touchmonitor.cpp
- TouchInputMonitor 仅负责 Shizuku 生命周期、原生监听器传输/启动与稳定协议解析。
- touchmonitor.cpp 直接通过 evdev 只读读取 /dev/input/event* 的 input_event，支持 Type-B slot、多点 tracking id、Type-A 与 BTN_TOUCH 单指回退。
- 触屏监听独立于 Root/灵敏度模式；不 EVIOCGRAB、不注入，不负责绘制。

TouchRegionOverlayEditorView.java
- 触屏显示四区域全屏悬浮调试器，由 AccessibilityService 直接覆盖目标应用。
- 仅在横屏显示，支持挖孔/安全区布局，并保存物理整屏归一化区域坐标。

FloatingVideoOverlayView.java
ChromaKeyVideoSurfaceView.java
- 超级自定义按显中的悬浮图片/视频组件。
- 使用 OpenGL ES 外部纹理实时渲染透明度与色键抠图；导入时支持点击视频取色和强度预览。

SensitivityProxyController.java
native/sensitivityproxy.cpp
- 处理鼠标和右摇杆灵敏度倍率。
- 倍率变化只刷新代理。

FontManager.java
- 导入并缓存 TTF / OTF 字体。

KeyOverlayView.java
NativeKeyCanvasView.java
- 键盘、鼠标、自定义按键的原生窗口与绘制。

KeyAppearance.java
- 统一按键形状、按下文字颜色和扩散动画。

FullKeyboardOverlayView.java
- 输入法打开时显示只读全键盘。

KeyPromptOverlayView.java
- 最近按键、CPS 和释放停留。

MouseTrajectoryView.java
- 鼠标轨迹显示与动画。

GamepadOverlayView.java
- 左右摇杆、ABXY、肩键和扳机绘制。

GlobalHtmlWebView.java
- 自定义 HTML 渲染层。
- HTML API v10。
- 高频 pointer / gamepad 按显示帧合并。
- key / mouse 事件会先更新内存状态，再派发事件。
- 支持 localStorage / sessionStorage。

HtmlGuideActivity.java
- 应用内 HTML API 文档与示例。

CloudNoticeChecker.java
- 登录后读取云端公告。

UpdateChecker.java
- 检查云端版本号。

SignatureVerifier.java
- 启动时校验 APK 签名。

native/keyengine.cpp
- 键盘和鼠标位状态、CPS 计数。

native/gamepadmonitor.cpp
- 手柄 evdev 只读监听与设备选择。

建议阅读顺序
MainActivity
-> OverlayState
-> AxonInputAccessibilityService
-> 各 OverlayView
-> GlobalHtmlWebView
-> native
