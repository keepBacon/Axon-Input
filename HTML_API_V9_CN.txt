Axon Input HTML API v9

一、运行方式
- 导入一份 HTML 后，每个开启的悬浮显示会各自创建一份页面。
- 使用 KeyDisplay.type 判断当前页面对应哪个显示，只创建当前窗口需要的 DOM。
- HTML 可使用 CSS、JavaScript、SVG、Canvas、Web Animations API。
- 网络请求默认禁止，不开放 addJavascriptInterface，不提供系统高权限调用接口。

二、window.KeyDisplay
apiVersion = 9
version = v26
type = 当前显示类型
types = 全部显示类型数组
getState() = 最近状态对象
on(name, fn) = 订阅事件，返回取消订阅函数
once(name, fn) = 只订阅一次
has(capability) = 当前窗口是否支持某能力
css(name, value) = 设置 CSS 变量
clamp(value,min,max) = 限制数值范围
lerp(a,b,t) = 线性插值
raf(fn) / cancelFrame(id) = 动画帧辅助函数

四、事件
keydisplay:init      页面初始化
keydisplay:update    设置、主题、大小等低频完整状态变化
keydisplay:key       单个键位变化
keydisplay:mouse     鼠标左右键和 DPS
keydisplay:pointer   鼠标相对移动，高频，按显示帧合并
keydisplay:gamepad   手柄摇杆/扳机/按键，高频，按显示帧合并

pointer/gamepad 不会每次重建完整 JSON。Android 只修补 window.__KEYDISPLAY_STATE__ 中对应字段，
因此在事件回调中调用 KeyDisplay.getState() 仍能读取最新值。

七、手柄语义
推荐读取 gamepad.buttons.a / b / x / y。
不要用 north/west 判断文字标签。Android KeyEvent 语义会负责修正部分设备的 X/Y 标签差异。

八、低性能消耗建议
1. pointer/gamepad 使用对应细粒度事件，不要在每个事件重建整棵 DOM。
2. 静止后停止 requestAnimationFrame。
3. 动画优先 transform、opacity、Web Animations API。
4. Canvas 只重绘变化区域或当前帧，不创建永久空转循环。
5. 相同文本、颜色、class 未变化时不要重复写 DOM。
6. 根据 KeyDisplay.type 只初始化当前窗口需要的元素。
7. HTML 关闭后 WebView 会销毁；不使用 HTML 时原生 Canvas 路径开销更低。
